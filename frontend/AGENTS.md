# 用户确认的箭头设计规范

- 所有 UI 箭头统一使用 `TripleArrow.vue`，由三个 Lucide chevron 图标组成，依次流动，不使用文字 `>>>` 或单箭头。
- 默认方向为 right，普通跳转和外链也向右；返回/上一页为 left，向下展开为 down，收起为 up。方向随操作状态变化。
- 窄按钮和行内入口使用 compact。遵循 prefers-reduced-motion，在减少动态效果设置下禁用动画。
- 不再自行增加单独箭头 SVG、Unicode 箭头或重复的三箭头动画。
- 社区助手的发送按钮按用户最新要求使用 Lucide `send` 纸飞机图标；其他箭头继续遵循三箭头规范。
- 展开控件只显示动态三箭头，不加“展开 / 收起”文字，也不加外围圆框或圆形底色；状态通过箭头方向表达。
